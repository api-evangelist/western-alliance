# Western Alliance Bank

> Western Alliance Bancorporation (NYSE: WAL) is a Phoenix, Arizona super-regional bank holding company (~$80B in assets) whose principal subsidiary, Western Alliance Bank (Arizona state-chartered commercial bank, member FDIC), runs a first-party WAB API Developer Portal ("Developer Hub"). It exposes a commercial Treasury Management open-banking API for balance and transaction information, check images, funds transfers, and stop payments. Access is partner/customer-gated: specifications download from the Developer Hub only with WAB-issued credentials, and authentication uses OAuth2 client-credentials (Client ID + Client Secret), a Client Certificate (mTLS), and access tokens across UAT and Production. No public consumer FDX or CFPB Section 1033 data-access API is documented, and no OpenAPI/Swagger is publicly downloadable.

## APIs

- [Western Alliance Bank API (Treasury Management)](https://developer.westernalliancebank.com/s/): Commercial open-banking API for balance and transaction information, check images, funds transfers, and stop payments. Spec and endpoints are gated behind the WAB Developer Hub and issued credentials.

## Authentication

- OAuth2 client-credentials (Client ID + Client Secret) + Client Certificate (mTLS) + access token, across UAT and Production. See authentication/western-alliance-authentication.yml.
- Portal login IdP (Salesforce Identity) OIDC discovery: https://developer.westernalliancebank.com/.well-known/openid-configuration
